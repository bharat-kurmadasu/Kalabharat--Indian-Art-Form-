# KalaBharat — Interactive Indian Art Map

Academic project for **Indian Art Forms – CO1**.

## Features
- Interactive India map using React Leaflet
- Clickable locations for Indian art heritage
- Search and category filtering
- Artwork images with source links
- Descriptions, periods and historical context
- Responsive design for laptop and mobile

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Vercel deployment
Import the GitHub repository into Vercel.
- Framework: Vite (auto-detected)
- Root Directory: `./`
- Build Command: `npm run build`
- Output Directory: `dist`

## GitHub upload
Upload the **contents of this folder** to the root of your GitHub repository.
The repository root must directly contain `package.json`, `index.html`, and `src/`.
Do **not** upload this ZIP as the only repository file.
